## Uso y mantenimiento

- **Estado:** hechos fechados y evidencia; evita repetir allí contratos completos.
- **Requisitos:** criterios del producto; enlaza las tareas que los cierran.
- **Decisiones:** separa aceptación expresa, implementación observada y propuesta.
- **Plan:** tareas concretas; marca una tarea completa solo con su evidencia.
- **Relevo:** resumen breve, siguiente acción y referencias.

La documentación histórica se conserva sin editar. Sus afirmaciones de validación no sustituyen resultados actuales. El corte se basa en el checkout local `7399e86`, revisión de código y pruebas, y la prioridad expresada por el usuario; no se recuperaron conversaciones previas ni resultados remotos de CI.
